# C++ Maze Solver

C++ maze-solving project demonstrating grid traversal and pathfinding techniques for finding a route from a start point to a target.

## Features

- Grid-based maze representation
- Start-to-target traversal
- Pathfinding practice in C++
- Small, focused algorithm implementation

## Build

```bash
g++ -std=c++17 -O2 -o maze-solver *.cpp
./maze-solver
```
